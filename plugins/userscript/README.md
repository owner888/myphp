# User Scripts for myphp

myphp's official User Scripts plugin, a port to PHP of IINA's
[plugin-userscript](https://github.com/iina/plugin-userscript). A user script is PHP code each
player runs with `$iina`, the plugin API, as a plugin's entry is given it: Manage User Scripts…
(Cmd+Shift+U) lists, adds, edits and deletes them.

## Install

In myphp, Settings > Plugins > Get Plugins…, choose Userscript; or enter
`owner888/myphp-plugin-userscript`.

## Languages

English, Simplified and Traditional Chinese, and Japanese (`locales/`): it speaks the language the app shows. A translation to another language is a `locales/<tag>.json` of the same keys as `en.json`.
